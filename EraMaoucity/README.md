# 榨取魔城 0.10（MVP）

Emuera 文字游戏 · 魔王经营 · **成人向（全部角色为成年人）**

以 `EraMaou 0.92` 的工程结构为蓝本，按《榨取魔城 世界观与玩法融合设计》实现的最小可玩版本：
**调教 → 榨取体液 → 养设施 → 召兵 → 出征掠夺 → 抓更多人 → 调教**。

---

## 一、怎么跑

1. 双击本目录里的 `Emuera1822.exe`（已内置，源自 EraMaou 0.92）。
2. 标题画面输入数字后按回车：`0` 新游戏 / `1` 读档 / `2` 退出。
3. 主菜单同样输入数字 + 回车。

> 菜单编号是 **100–109**，不是 1–9。原因：Emuera 的 SHOP 流程会把 0–99 当成「购买商品」，只有 100 以上才会交给 `@USERSHOP` 处理。这是本作最容易踩的坑，已在代码注释里标出。

| 编号 | 功能 | 消耗 |
| --- | --- | --- |
| 100 | 调教（9 条指令） | 1 AP |
| 101 | 榨取（乳/爱液/尿/血） | 1 AP |
| 102 | 设施分配（6 种产线） | 0 AP |
| 103 | 征召兵力（80 魔力/只） | 1 AP |
| 104 | 出征（村庄/城镇/王都） | 1 AP |
| 105 | 实验室（5 种改造） | 1 AP |
| 106 | 强化城防（50 魔力 → 城防 +5） | 0 AP |
| 107 | 结束回合 | — |
| 108 / 109 | 存档 / 读档 | — |

## 二、核心循环

```
一天 2 点行动力（AP）
  ├─ 调教：涨敏感/服从、掉反抗，产出魔力 + 少量体液，推进恶堕
  ├─ 榨取：按类型采集乳汁/爱液/尿液/血液
  ├─ 设施：把已服从的人塞进产线，日终自动产出
  ├─ 召兵：魔力 → 兵力（战力 = 100 + 兵力×5 + 恶堕者×30+）
  └─ 出征：战力达标就抢村庄/城镇 → 金币 + 新俘虏
结束回合 → 设施结算 → 入侵者下潜 → 陷阱伤害/捕获 → 新一天
```

**失败**：入侵者抵达第 9 层且战力压过你 → 结局「魔王城陷落」。
**通关**：战力 400 + 兵力 10，进攻王都 → 结局「榨取帝国」。

### 3.3 状态与恶堕

- **抵抗** → 服从（服从 ≥50 且反抗 ≤40）→ **恶堕**（恶堕度 ≥10 且服从 ≥80）
- 只有「服从 / 恶堕」能被安排进设施；恶堕者出征时提供额外战力。
- 恶堕度来源：触手调教 +2、兽奸 +2、实验室「恶堕催化」+4。

### 3.4 设施（日终结算）

| 设施 | 产出 | 代价 |
| --- | --- | --- |
| 触手深渊 | 爱液 +20~、魔力 +30 | 体力 −8 / 气力 −10 |
| 哥布林巢穴 | 精液 +15、12% 受孕 | 同上 |
| 自动调教机 | 魔力 +40 | 气力额外 −10 |
| 榨乳农场 | 乳汁 +40 | 同上 |
| 采血室 | 血液 +30 | 体力额外 −25 |
| 育儿室 | 妊娠倒计时，产下后 +100 魔力、解锁泌乳 | — |

体力归零 → 该角色死亡并从名册移除（这就是「可持续榨取」的边界）。

### 3.5 实验室（每次进入消耗 1 AP，改造只花魔力）

泌乳改造 200 / 敏感强化 150 / 服从灌输 300 / 体力强化 150 / 恶堕催化 400。

### 3.6 入侵与城防

- 每天 70% 概率新增 1 名入侵者（上限 6），从第 1 层开始下潜。
- 城防决定两件事：迟滞概率（`30 + 城防/2` %）与每日陷阱伤害（`城防/2 + 5`）。
- 入侵者体力归零 → 被拖进地牢成为奴隶；抵达第 9 层 → 与魔王决战。

```

├── Emuera1822.exe        引擎（可直接双击运行）

    ├── SYSTEM.ERH        全局变量（资源、奴隶/入侵者数组、常量）
    ├── title.ERB         标题画面
    ├── main.ERB          初始化 / 主界面 / 主菜单 / 回合结算 / 两个结局
    ├── train.ERB         调教 9 条指令 + 榨取菜单 + 状态收束

    ├── lab.ERB           实验室
    └── util.ERB          冒险者生成、捕获、转奴隶、战力计算
```

改数值：`SYSTEM.ERH`（初始资源、上限）与各文件里的常量。
改文案：`train.ERB` 的 SELECTCASE 分支、`main.ERB` 的结局段落。
加指令：在 `train.ERB` 的 `@TRAIN_ACTION` 里加 CASE，并在菜单文本里加一行。

## 五、验证记录

| 检查 | 结果 |
| --- | --- |
| 结构检查（块配平 / 重名 / CALL 目标 / 标签 / #DIM 位置） | 8 文件 · 25 函数 · **0 错误 0 警告** |
| 语义体检（ERH 变量声明 / 调用参数个数 / 局部与全局重名） | **0 错误** |
| Emuera 1.822 实际加载 | 成功，`emuera.log` **无错误**（标题栏显示「榨取魔城 0.10」） |
| 交互冒烟（点进主菜单、调教一次） | **未自动执行**——需要人工点一次确认手感 |

修正过的两个 Emuera 坑（已在代码里规避）：

1. `A`~`Z`、`DAY` 是内置变量，不能 `#DIM`；本作把天数改名为 `天数`。
2. 形参必须写成 `@FUNC(ARG)` / `@FUNC(ARG, ARG:1)`，不能自取名字（如 `(IDX)` 会报「識別子として解析できない」）。
3. SHOP 流程里 0–99 是「购买」，所以主菜单用 100+，且 `@USERSHOP` 不再自己 `INPUT`。

## 七、引擎验证：确认这是 ERA 引擎工程

本作 **不是** 独立程序，也没有任何编译产物：全部逻辑都是 `.ERB` / `.ERH` 文本，由 **Emuera 1.822**（`Emuera1822.exe`）在运行时解释。

| 证据 | 怎么做 | 结果 |
| --- | --- | --- |
| 引擎读的是我们的脚本 | 用本目录的 `Emuera1822.exe` 启动 | 窗口标题显示 `榨取魔城 0.10`（来自 `CSV/GAMEBASE.CSV`） |
| 引擎真的在解析 ERB | 在项目副本的 `title.ERB` 末尾故意写一行非法命令再启动 | 生成 `emuera.log`：`title.ERB:34行目: 解釈できない行です` + `THIS_IS_NOT_A_COMMAND` —— 文件与行号都由引擎报出 |
| 正常工程无错误 | 删掉日志后重新启动 | 不产生 `emuera.log`，说明 8 个 ERB / 25 个函数全部解析通过 |

复现方式（PowerShell）：

```powershell
cd "C:\Users\Administrator\Desktop\101\榨取魔城"
Remove-Item emuera.log -ErrorAction SilentlyContinue
Start-Process .\Emuera1822.exe
# 启动后标题栏应为「榨取魔城 0.10」；正常工程不会生成 emuera.log
```

代码本身用的都是原生 ERB 语法（统计自本工程）：

```
IF/ENDIF 70/70 · SELECTCASE 10 · CASE 62 · WHILE/WEND 4/4 · FOR/NEXT 7/7
CALL 33 · RETURN 50 · GOTO 20 · BEGIN 14
PRINTL 77 · PRINTFORML 38 · PRINTW 37 · PRINTFORM 18 · INPUT 11
CLEARLINE 26 · SAVEGAME/LOADGAME 1/2 · 函数 25 个
```

数据层用 `SYSTEM.ERH` 的 `#DIM SAVEDATA` 数组（42 个全局变量），存档走引擎自带的 `SAVEGAME`/`LOADGAME`，没有外部脚本、没有联网、没有额外运行时。

也就是说：换一个 Emuera 版本（1.822 以上）同样能跑；把 ERB 目录交给任何一个 era 工程也能被引擎识别。
